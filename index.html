From upcoming bills to recorded payments.

Track obligations before the final amount is known. Collect the details, confirm what is due, and mark it paid when you are done.

  1. Draft

    See obligations for future periods before data collection starts.

  2. Collecting data

    Add or correct amounts and dates manually or through an integration.

  3. Ready

    The amount and due date are confirmed. The obligation is ready to pay.

  4. Paid

    Payment is marked as complete, with the bill details kept for reference.

Already have complete details? Start at Ready. Reopen an obligation when details need correcting, or cancel it while collecting data. Integrations can flag inconsistent bill data for attention.

See what still needs paying.

The calendar shows when bills are due. The forecast shows unpaid amounts by due date, separately for each currency.

Understand a change in your bill

Keep individual charges, such as a fixed fee and usage, alongside the total. Compare recurring components across billing periods to see which charge changed.

Keep a record of payment

Mark a bill as paid or let a supported integration update its status. Amounts, components and action history stay available. Oblidog tracks payments; it does not send bank transfers.

Build the integration you need.

Bring data from your own sources into the same bill workflow. Use the API directly, or start with the Python SDK and a working example.

Integration API
Sync amounts, dates, bill components and payment status. Each integration key is scoped to one category.
Python SDK
Use a Python client to update obligations and report integration runs, with guides for common import tasks.
Example integration
Use the demo adapter as a starting point: fetch data, update an obligation and mark it ready. Adapt the source-specific logic to your needs.

Run integrations separately on your infrastructure, on your schedule. Each needs its own setup and data-source access. Manual entries work alongside imported data.

Run Oblidog yourself.

Self-hosted means the application and its database run on a machine you manage. The standalone setup uses Docker Compose and includes PostgreSQL.

Read the self-hosting guide

  1. Install and configure

    Follow the guide to set up the containers, application secrets and access to your instance.

  2. Add your recurring categories

    Create categories for bills such as rent, electricity and insurance, then review their billing periods and amounts.

  3. Connect integrations when you need them

    Start with manual entries. Add an integration later to import data into a category.
